# alice_masterclass
Welcome to alice masterclass interface.

This masterclass is meant to provide an example of all the
steps of an anlysis in high energy physics.
the main focus in this case is the study of the charmonia
in Pb-Pb collisions. Your goal is to find the best analysis
cuts to select the signal candidates and then extract the
number of J/psi e Psi(2S).

With this interface you can:
 - inspect the different observables (mass, pT, eta, ecc..)
 - study the analysis cuts that maximize the signal you are searching
 - fit the data to extract the number of candidates
 - Compare the results with other analyzers

Enjoy!

- To run the masterclass you have to do:
  ```ruby
  root -l splash.C
  ```
